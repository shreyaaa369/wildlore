缙云山知野自然教育资源网站 · 分类与课程版 V5

打开方式：Windows 双击“双击启动网站.cmd”，或在当前目录运行 python start-local.py，随后浏览器访问显示的 localhost 地址。页面默认从首页打开。在线高德地图底图及路线规划需要网络连接、有效的 Web JS API Key/安全密钥及相应域名配置。

数据完整性：原始 resource-points.js 309 项资源全部保留。新增 curated-resources.js 筛选约 90 项代表性资源，仅控制默认显示密度；取消地图“仅显示代表性点位”，即可显示全部资源；直接搜索名称或编号也可定位未入选的资源。

七大类颜色：生物资源、生态资源、地质地貌、水文气象、人文资源、教育设施、服务与活动；原始细分类别保留在点位详细档案中。筛选依据包括教育主题/活动描述完整程度、代表意义、位置间距和区域覆盖，属于展示选择而非对资源价值的绝对评价。

课程：森林生态观察、鸟类与生物多样性、地质土壤探究、水环境与生态保护、历史文化寻访、山地气象与自然观察。左侧选择后生成教学站点、顺序、站点介绍以及步行路径。站点之间优先调用高德步行路线接口；若接口不支持、无路网或返回失败，则使用灰褐色虚线提示站点方向，虚线不是可通行路线。课程路线并未核实现场道路可通行性，受封闭区域/天气/陡坡影响，请以现场管理规定为准。

首页：资源分类概览按 309 项原始数据统计；知识图谱展示“类别—点位—教育主题”的可追溯关联，课程入口可跳转对应专题地图，档案可按类别筛选。资源搜索继续覆盖全部原始资源。

新增文件：curated-resources.js、nature-courses.js、course-routes.js。保留其余原有文件、识别工具链接、导航功能及原地图数据。

课程路径为自然教育教学路线规划，不能代替现场导航。实地活动前务必核实开放情况、路段安全和人员资质。
